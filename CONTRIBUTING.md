# Contributing

## Getting Started

```bash
git clone https://github.com/SENODROOM/sunan-abi-dawud.git
cd sunan-abi-dawud
```

## Making Changes

- JS changes → edit files in `src/`
- Python changes → edit files in `python/sahih_dawud/`
- Data changes → edit `data/dawud.json` then run `node scripts/build.mjs`

## Publishing

Publishing is automatic via GitHub Actions on every GitHub Release.
